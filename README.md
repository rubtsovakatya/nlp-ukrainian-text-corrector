# Коректор українського тексту

Вебзастосунок для автоматичного виправлення орфографічних, граматичних і пунктуаційних помилок в українських текстах за допомогою великої мовної моделі (LLM).

Проєкт розроблено в межах лабораторної роботи з курсу NLP.

## Функціональність

- Автоматичне виправлення помилок в українському тексті.
- Збереження початкового змісту та стилю.
- Виведення лише виправленого тексту без додаткових пояснень.
- Простий вебінтерфейс для введення тексту й перегляду результату.
- Використання одного API-виклику мовної моделі для кожної перевірки.

## Використані технології

| Технологія | Призначення |
|---|---|
| Python | Основна мова програмування |
| Streamlit | Створення вебінтерфейсу |
| Groq API | Взаємодія з мовною моделлю |
| GPT-OSS 20B | Обробка та виправлення тексту |
| Streamlit Community Cloud | Хмарне розгортання застосунку |

## Принцип роботи

1. Користувач вводить український текст і Groq API-ключ.
2. Застосунок формує запит до LLM, що містить системну інструкцію та введений текст.
3. Модель аналізує текст і виправляє знайдені помилки.
4. Виправлений текст відображається у вебінтерфейсі.

Для кожної перевірки виконується один виклик мовної моделі. Додаткове навчання моделі не проводиться.
